# ICEEA-2027-CUTM

## About

This repository contains the ICEEA 2027 CUTM website built with TanStack Start, TypeScript, React, and Tailwind CSS.

## Development

Prefer working locally? You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```

## Built with

- TanStack Start
- TypeScript
- React
- Tailwind CSS
